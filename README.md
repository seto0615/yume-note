# 夢ノート

熊谷正寿『一冊の手帳で夢は必ずかなう』および夢手帳・熊谷式の考え方を、スマホで開けるWebアプリにしたもの。
インストール不要、アカウント不要。データはすべて端末のブラウザ内にだけ保存される。

**公開URL** → https://seto0615.github.io/yume-note/

## 画面

| 画面 | 中身 |
|---|---|
| 人生時計 | 生年月日と想定寿命から残り日数を算出。1マス＝1週の人生カレンダーで、使った時間と残りの時間を一望する |
| やりたいことリスト | 6分野に夢を書き出す。具体的なイメージ・写真・実現する日・数値目標・小目標を持たせる |
| 夢・人生ピラミッド | 基礎（健康／教養／心）→ 実現（家庭／仕事）→ 結果（経済）の3段で並べ、空白の分野を炙り出す |
| 未来年表 | 実現日を持つ夢を年ごとに並べ、その年の自分の年齢を添える |
| DWMYリスト | 夢に紐づく行動を Daily / Weekly / Monthly / Yearly で習慣化し、日々チェックする |

## 設計の元にした考え方

- 時間＝命。人生をカウントダウンとして捉える
- 実現できるかどうかは考えず、ゼロベースで書き出す
- 「家が欲しい」ではなく「駅徒歩10分・110㎡・白の塗り壁」まで具体化する
- 達成期限と、実現したときの状態を数値化したものを目標として設定する（体重53キロ／TOEIC 800点／人脈15人）
- 6分野のバランスが取れてこそ、人生の究極の目標は達成される
- 1分野あたり7個までを目安に絞る
- 毎日確認し、頭の中に夢と目標をすり込む

## データの扱い

- 夢・習慣・写真はすべて `localStorage` にのみ保存される。サーバー送信は一切ない
- 写真は長辺900pxのJPEGに縮小して保存する
- 端末を移すとき・ブラウザの履歴を消すときは、設定画面から JSON で書き出して持ち運ぶ
- Service Worker により、一度開けばオフラインでも起動する

## スマホでの使い方

1. iPhone の Safari で公開URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. アイコンから起動するとアドレスバーのないアプリとして動く

Android の Chrome も同様に「ホーム画面に追加」でインストールできる。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # docs/ に出力（GitHub Pages の配信元）
npm run preview
```

GitHub Pages は `main` ブランチの `docs/` を配信元にしている。UIを変えたら `npm run build` して `docs/` ごとコミットする。

技術構成: React 19 + TypeScript + Vite。ランタイム依存は React のみ。

## デザイン

`tax.hatenabase.jp` の幾何学紋様を下敷きにした暗色版。
はてなベースの幾何学4トーン（navy `#0A2846` / blu `#2D5FA8` / sky `#A9C4E4` / pale `#DCE6F2`）と、
正方形・円・1/4円・葉型のタイル語彙だけで装飾している。6分野は色に加えてタイルの形でも識別できる。
